Q1: Implement Gradient Descent in Python use
linear regression where we try to fit a line y=mx+b ( 5
Marks)

Explanation:

1. Initialize m and b (slope and intercept) to zero.

2. Predict values using Y_pred = m*X + b.

3. Compute gradients for m and b using the

derivative of MSE.

4. Update parameters in the opposite direction of

the gradient.

5. Repeat for a number of epochs until

convergence.
